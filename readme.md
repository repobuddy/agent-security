# agent-security

Security and vulnerability remediation skills for AI agents.

## Install

```bash
npx skills add repobuddy/agent-security --all
```

## Skills

| Skill | Description |
|---|---|
| `fix-security-pr` | Detect and fix security/vulnerability failures in PRs — audit failures, CVEs, Dependabot conflicts |

## Usage

Once installed, the skill activates automatically when you ask your agent to fix a security or vulnerability-related PR failure.
